# Deep (non-root) foci

The operations in this section can be executed on any focus that is _not_
the root focus. Sibling navigation (`first`, `last`, `previous`, `next`)
is available directly on `JFieldFocus` and `JItemFocus`. The `delete`
extension method works on any focus but returns an error if the focus is
at the root.
