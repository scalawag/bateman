# Foci with an array value

The operations in this section can be executed on any focus that has a
`JArray` as its value. If the focus value type is statically known to be
`JArray`, these operations are available directly. If the value type is
`JAny`, you first need to @ref:[narrow](../any/narrow.md) to `JArray`.
