# Foci with an object value

The operations in this section can be executed on any focus that has a
`JObject` as its value. If the focus value type is statically known to be
`JObject`, these operations are available directly. If the value type is
`JAny`, you first need to @ref:[narrow](../any/narrow.md) to `JObject`.
